# ⏰ 우리반타이머

교실 TV·전자칠판용 큰 숫자 타이머 프로그램입니다.

## 기능
- **🕐 시계** – 현재 날짜·시각 + 세계시각 8개 도시(서울, 도쿄, 베이징, 뉴델리, 런던, 파리, 뉴욕, 시드니), 낮/밤 표시
- **⏱ 스톱워치** – 시작/멈춤, 구간 기록, 초기화
- **⏳ 타이머** – 30초~40분 빠른 설정, ±10초/1분/10분 조절, 진행 막대, 마지막 1분 주황·10초 빨강, 끝나면 화면 깜빡임 + 소리
- **⏰ 알람** – 여러 개 저장(껐다 켜기, 삭제), 메모 표시

## 단축키
| 키 | 기능 |
|---|---|
| 1 / 2 / 3 / 4 | 시계 / 스톱워치 / 타이머 / 알람 탭 |
| Space | 시작·멈춤 |
| R | 초기화 |
| L | 스톱워치 기록 |
| F11 | 전체화면 |
| 아무 키 / 화면 클릭 | 울리는 소리 멈춤 |

## exe 받기 (자동 빌드)
이 저장소에 올리면 GitHub Actions가 자동으로 Windows exe를 만듭니다.

1. 저장소 위쪽 **Actions** 탭 → **Build Windows EXE** 클릭
2. 가장 최근 실행(초록 체크) 클릭 → 아래 **Artifacts**의 `우리반타이머-windows` 다운로드
3. 압축을 풀면 `우리반타이머-포터블.exe`(설치 없이 실행), `우리반타이머-설치.exe`(설치형)

> 수동 실행: Actions 탭 → Build Windows EXE → **Run workflow**
> 릴리스로 올리기: `v1.0.0` 같은 태그를 푸시하면 Releases에 exe가 첨부됩니다.

※ 서명 없는 exe라 처음 실행할 때 Windows가 "PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누르세요.

## 내 PC에서 직접 빌드
```bash
npm install
npm start      # 바로 실행
npm run dist   # dist 폴더에 exe 생성
```
`index.html`만 브라우저로 열어도 그대로 사용할 수 있습니다.
